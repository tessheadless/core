Configuration reference

Tess is configured only through environment variables. Secrets must come from the environment or a secrets manager, never from files committed to a repository. A commented template is provided as .env.example.

Generate every secret with a fresh random value:

openssl rand -hex 32

License​

VariableDefaultDescription
TESS_LICENSEcommunitycommunity (personal use) or commercial (any commercial use, see Community & Enterprise). The commercial license excludes the embedded n8n workflow editor: TESS_N8N_URL is then ignored.
TESS_LICENSE_KEYRequired with commercial: your license key (tess_…). Tess refuses to start without a valid one. Never logged or returned by the API.

Secrets and authentication​

VariableDefaultDescription
TESS_ID_SECRETrequiredKey encrypting the opaque API ids. At least 32 bytes.
TESS_REF_SECRETrequiredKey for stable ref values. At least 32 bytes, different from TESS_ID_SECRET.
TESS_SESSION_SECRETrequiredKey signing user sessions. At least 32 bytes. Changing it signs everybody out.
TESS_ADMIN_TOKENunsetBootstrap token with full access (acts as the "system" Owner). At least 32 characters. Use it to create the first Owner, then remove it.
TESS_ID_SECRET_PREVIOUSunsetComma-separated previous id secrets, still accepted for decoding during a key rotation.
TESS_ID_TTL24hLifetime of opaque ids (900s, 30m, 24h, 7d).
TESS_SESSION_TTL12hLifetime of user sessions.
TESS_SECRETS_KEYTESS_SESSION_SECRETKey encrypting integration secrets stored in the database (webhook signing secrets and headers, storage keys of translation delivery targets). At least 32 bytes. Changing it makes them unreadable: re-enter them.

Database​

VariableDefaultDescription
TESS_DATABASEmemorypostgres, mysql, sqlite, mongodb, dynamodb, rocksdb or memory. The Docker image sets rocksdb.
DATABASE_URLFor postgres, mysql, sqlite: postgres://user:pass@host:5432/db, mysql://user:pass@host:3306/db?ssl-mode=required, sqlite:///data/tess.db. Its scheme must match TESS_DATABASE.
TESS_DB_MAX_CONNECTIONS10 (2 on Lambda)SQL connection pool size.
MONGODB_URLFor mongodb.
MONGODB_DATABASEtessMongoDB database name.
DYNAMODB_TABLEtessDynamoDB table (key schema pk/sk).
DYNAMODB_ENDPOINTunsetCustom endpoint, e.g. DynamoDB Local.
DYNAMODB_CREATE_TABLEfalseCreate the table at startup if missing (local development).
ROCKSDB_PATHdata/rocksdbRocksDB directory.

AWS credentials and region for DynamoDB come from the standard AWS chain: the IAM role of the function or task, AWS_* variables, or a profile. See Databases.

Media​

VariableDefaultDescription
TESS_MEDIA_STOREfs (s3 on Lambda)fs or s3.
TESS_MEDIA_DIRdata/mediaDirectory for fs.
TESS_S3_BUCKETBucket for s3 (required).
TESS_S3_ENDPOINTunsetEndpoint of S3-compatible services (Garage, MinIO, R2…).
TESS_S3_PUBLIC_ENDPOINTTESS_S3_ENDPOINTEndpoint as browsers reach it, for presigned file URLs, when Tess uses an internal one (e.g. http://garage:3900 in Docker, http://localhost:3900 or https://s3.example.com for browsers).
TESS_S3_REGIONfrom the AWS chainRegion (Garage uses garage by default).
TESS_S3_FORCE_PATH_STYLEtrue when an endpoint is setPath-style URLs, needed by most self-hosted services.
TESS_S3_ACCESS_KEY_ID / TESS_S3_SECRET_ACCESS_KEYunsetExplicit credentials. Set both, or neither to use the default AWS chain.
TESS_S3_CREATE_BUCKETfalseCreate the bucket at startup if missing.
TESS_MEDIA_PUBLIC_URLunsetPublic base URL (CDN) of the bucket: asset URLs become {base}/{key}.
TESS_MEDIA_URL_TTL_SECS3600Lifetime of presigned upload/download URLs.
TESS_MEDIA_MAX_UPLOAD_BYTES104857600 (100 MiB)Maximum file size.

See Media storage.

TYPESENSE_URLe.g. http://typesense:8108.

Cache​

VariableDefaultDescription
TESS_CACHEnonenone, memory (one instance), or a server shared by every instance: valkey, redis, keydb or dragonfly (any server speaking the Redis protocol works).
TESS_CACHE_URLredis://[user:password@]host:6379/0, or rediss:// for TLS. VALKEY_URL and REDIS_URL are read too.
TESS_CACHE_TTL_SECS60Lifetime of cached responses; capped at half of TESS_MEDIA_URL_TTL_SECS and TESS_ID_TTL.
TESS_CACHE_PREFIXtess:Prefix of keys and channels, to share a server between installs.
TESS_CACHE_MAX_ENTRIES10000memory only.

See Cache.

Plugins​

VariableDefaultDescription
TESS_PLUGINStrueEnable the WebAssembly plugin system.
TESS_PLUGIN_ALLOW_HTTPtrueWhether admins may allow plugins to make HTTP requests at all.
TESS_PLUGIN_MAX_TIMEOUT_MS10000Highest per-plugin timeout an admin can set (plugins default to 1000 ms).
TESS_PLUGIN_MAX_MEMORY_PAGES1024 (64 MiB)Highest per-plugin memory cap, in 64 KiB pages (plugins default to 256 = 16 MiB).
TESS_PLUGIN_MAX_MODULE_BYTES20971520 (20 MiB)Maximum module size.

Translations, webhooks, workflows, forms and calendars​

VariableDefaultDescription
TESS_I18NtrueEnable translations (API, /i18n/{format}/{file}, delivery targets).
TESS_WEBHOOKStrueEnable webhooks.
TESS_WEBHOOK_ALLOWED_HOSTSunset (any)Comma-separated hosts webhooks may target (*.example.com allowed).
TESS_WEBHOOK_TIMEOUT_SECS10Timeout of one delivery attempt.
TESS_WEBHOOK_MAX_ATTEMPTS5Attempts per delivery (retries after 10 s, 1 min, 5 min, 30 min). On AWS Lambda: one inline attempt.
TESS_N8N_URLunsetWhere Tess reaches n8n, e.g. http://n8n:5678. Enables the /n8n/ proxy and the admin Workflows page. Not on AWS Lambda.
TESS_N8N_PATH/n8n/Path the n8n editor is served under; n8n must use the same N8N_PATH.
TESS_FORMStrueEnable forms (API, GET/POST /api/forms/<slug>).
TESS_FORMS_RATE_LIMIT10Submissions accepted per visitor and form, per minute.
TESS_CALENDARStrueEnable calendars: linked Google calendars and cal.diy booking pages.
TESS_GOOGLE_CLIENT_ID, TESS_GOOGLE_CLIENT_SECRETunsetGoogle OAuth client for calendars. Without them, Admins set one in the admin (stored encrypted).
CALDIY_PUBLIC_URL, CALDIY_DB_PASSWORD, CALDIY_NEXTAUTH_SECRET, CALDIY_ENCRYPTION_KEYThe caldiy Compose profile: see Calendars.

HTTP and GraphQL​

VariableDefaultDescription
PORT8080HTTP port (ignored on Lambda).
TESS_PUBLIC_READtrueAnonymous requests may read PUBLISHED content.
TESS_CORS_ORIGINS*Comma-separated allowed origins, or *.
TESS_GRAPHIQLtrueServe the GraphiQL IDE on GET /graphql.
TESS_INTROSPECTIONtrueGraphQL introspection (the admin UI's review queue uses it).
TESS_DEFAULT_PAGE_SIZE100Default first of list queries.
TESS_MAX_PAGE_SIZE1000Maximum first of list queries.
TESS_MAX_QUERY_DEPTH16Maximum GraphQL query depth.
TESS_SCHEMA_REFRESH_SECS10How often an instance checks for model and plugin changes made elsewhere.
TESS_ADMIN_DIRadmin/dist/client if presentDirectory of the built admin UI, served under /admin/.

Logging​

VariableDefaultDescription
RUST_LOGinfoLog filter, e.g. info,tess_graphql=debug.
TESS_LOG_FORMATtext (json on Lambda)Set to json for structured logs.

Build-time features​

The tess-server package has one cargo feature per backend, so you can build smaller binaries:

FeatureEnables
sql (aliases postgres, mysql, sqlite)the SQL backend
mongodbMongoDB
dynamodbDynamoDB
rocksdbRocksDB (needs clang and cmake to build)
s3S3-compatible media store
lambdaAWS Lambda runtime

All are on by default. For example:

cargo build --release -p tess-server --no-default-features --features sql,s3
# binary: target/release/tess

Choosing a backend that the binary was built without fails at startup with a clear message.
