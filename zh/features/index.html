功能

一个二进制文件，整个内容平台

Tess 集成了 API、管理后台和业务规则。数据库、媒体存储和托管方式由你选择。

全部功能

  • 交给 AI 来运营

    内置的 MCP 服务器让 Claude、Cursor 和任何 MCP 客户端读取你的模型，并用自然语言创建、编辑和发布内容，权限与 API 完全相同。

  • 运行时定义模型

    在生产环境中通过管理后台或 API 创建内容类型。GraphQL schema 即时重新生成：无需重新构建，无需重新部署。

  • GraphQL 优先

    为每个模型生成带类型的查询、过滤、排序、分页、关联和 mutation，并内置 GraphiQL IDE。

  • 用你自己的数据库

    PostgreSQL、MySQL、SQLite、MongoDB、DynamoDB 或内嵌的 RocksDB。每个后端都通过同一套一致性测试。

  • 审核工作流

    每个条目都有草稿和发布，每种内容类型还可选用“提交 → 批准”工作流，所有版本均可用。

  • 角色与限定范围的令牌

    Owner、Admin、Contributor、Reviewer 和 Member 角色，可按需限定到部分内容类型，并为机器提供限定范围的 API 令牌。

  • 沙箱插件

    由管理员在运行时安装的 WebAssembly 插件，可用 Rust、Go、JavaScript 等语言编写，带有超时和内存限制。

  • 无服务器或容器

    同一个二进制文件既可作为 HTTP 服务器运行（Docker、虚拟机、Kubernetes），也可作为 AWS Lambda 函数运行。

  • 媒体库

    上传到兼容 S3 的存储（Garage、MinIO、AWS S3、Cloudflare R2）或本地文件系统，支持预签名直传。

  • 全文搜索

    Typesense 索引与内容保持同步，背后是可替换的搜索引擎接口。

  • 隐私优先的设计

    API 中使用不透明、会过期、经过加密的 ID：数据库 ID 永远不会离开服务器。

  • 可移植的模型

    tess-transfer 将内容模型和用户导出为 YAML 或 JSON，便于版本管理或在实例之间复制。

字段类型

TEXT（长度范围、正则格式）、MARKDOWN（拒绝原始 HTML）、INT、FLOAT、BOOLEAN、DATETIME、DATE、UUID、PASSWORD（哈希存储、只写）、JSON、ENUM、RELATION（单个或多个）、COMPONENT（可复用的字段组，单个或可重复）以及 DYNAMIC_ZONE（混合多种组件的列表）。本网站的页面就是用动态区域构建的。
