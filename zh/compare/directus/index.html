Tess 对比 Directus

基于 SQL 数据库的数据平台（Node.js）

一个 Node.js 平台，可把现有 SQL 数据库变成 REST 和 GraphQL API，并附带管理应用。

逐项对比

Tess 与 Directus 的对比
对比项TessDirectus
思路Tess 管理自己的存储和 schema映射现有 SQL 数据库的表
数据库PostgreSQL、MySQL、SQLite、MongoDB、DynamoDB、RocksDBSQL 数据库：PostgreSQL、MySQL、MariaDB、SQLite、MS SQL、Oracle、CockroachDB
API根据模型生成的 GraphQLREST 和 GraphQL
审核工作流内置，按内容类型设置需用权限和 Flows 自行搭建
自动化每次写入时运行插件内置 Flows（事件驱动的自动化）
许可证Community（个人使用）/ Enterprise（商业使用）Business Source License：收入低于门槛时免费，超过则需商业许可证

以下情况选择 Directus…

  • 你必须原样开放一个现有的 SQL 数据库。
  • 你需要内置的自动化流程。

以下情况选择 Tess…

  • 你从内容模型出发，而不是从现有的表出发。
  • 你需要 NoSQL（MongoDB、DynamoDB）、内嵌数据库或 AWS Lambda。

从 Directus 迁移到 Tess

每个 Directus collection 都变为一个 Tess 内容类型，其关联字段变为 RELATION 字段。用 tess-transfer 的 YAML 格式编写并导入，再通过两边的 GraphQL API 复制数据项。
