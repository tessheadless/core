Tess 对比 Sanity

带开源编辑工作室的托管内容平台

一个托管的 Content Lake，配有可定制的开源 React 编辑工作室，以及自有查询语言 GROQ。

逐项对比

Tess 与 Sanity 的对比
对比项TessSanity
交付方式由你自己运行的软件托管的 Content Lake；工作室开源，可自行部署
内容模型管理后台或 API，立即生效用 JavaScript/TypeScript 代码编写 schema
API根据模型生成的 GraphQLGROQ，外加可部署的 GraphQL API
编辑带草稿和审核的管理后台在高度可定制的工作室中实时协作编辑
数据位置你的服务器和你的数据库Sanity 的云
价格Community 版个人使用免费；商业使用需 Enterprise 许可证免费方案，之后按用量和席位付费

以下情况选择 Sanity…

  • 你需要实时协作和深度定制的编辑工作室。

以下情况选择 Tess…

  • 你希望内容保存在自己的数据库中，使用标准的 GraphQL API，无需学习新的查询语言。

从 Sanity 迁移到 Tess

Sanity 的文档类型和对象对应为 Tess 的内容类型和组件；混合类型的数组变为 DYNAMIC_ZONE 字段。用 tess-transfer 导入模型，再把 Sanity 导出的文档通过 Tess GraphQL API 复制过来。
