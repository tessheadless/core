Tess 对比 Contentful

可组合内容平台（SaaS）

以 SaaS 形式提供的企业级无头 CMS，提供 REST 和 GraphQL 内容分发 API 以及庞大的应用生态。

逐项对比

Tess 与 Contentful 的对比
对比项TessContentful
交付方式由你自己运行的软件仅提供托管 SaaS
API根据模型生成的 GraphQLREST 分发与管理 API，外加 GraphQL Content API
内容模型管理后台或 API，立即生效Web 应用或管理 API，支持多环境
数据位置你的服务器和你的数据库Contentful 的云
本地化暂不支持按字段的内容本地化内置多语言区域
可扩展性沙箱 WebAssembly 插件App Framework 和应用市场
价格Community 版个人使用免费；商业使用需 Enterprise 许可证免费方案，之后是有用量限制的付费方案

以下情况选择 Contentful…

  • 你需要带 SLA、支持众多语言区域并拥有庞大应用市场的企业级 SaaS。

以下情况选择 Tess…

  • 你希望掌控基础设施和数据。
  • 相比用量限制，你更喜欢可预期的许可证。

从 Contentful 迁移到 Tess

Contentful 的内容类型及其字段可对应为 Tess 内容类型；引用变为 RELATION 字段，资源变为指向 Asset 的关联。用 tess-transfer 导入模型，再借助 Contentful 导出文件和 Tess GraphQL API 复制条目。
