Tess 对比 WordPress

传统 CMS（PHP），可用作无头 CMS

全球使用最广泛的 CMS，一个带主题、插件和 REST API 的 PHP 应用，常通过 WPGraphQL 以无头方式使用。

逐项对比

Tess 与 WordPress 的对比
对比项TessWordPress
架构无头：只管内容，前端任选带主题的一体化建站工具；可通过其 API 以无头方式使用
内容模型带校验的类型化模型，在管理后台或 API 中定义文章和页面；自定义文章类型和字段需通过代码或 ACF 等插件实现
API根据模型生成的 GraphQL内置 REST API；GraphQL 通过 WPGraphQL 插件提供
技术栈Rust 二进制文件，六种数据库后端PHP 搭配 MySQL 或 MariaDB
编辑工作流按内容类型的草稿、审核、发布草稿、待审核和发布；更多功能需通过插件
可扩展性沙箱 WebAssembly 插件数以万计的 PHP 插件和主题
许可证Community（个人使用）/ Enterprise（商业使用）GPLv2 或更高版本

以下情况选择 WordPress…

  • 你想要一个带主题、由非开发人员搭建的网站。
  • 你依赖某个特定的 WordPress 插件或其庞大的生态。

以下情况选择 Tess…

  • 你的内容要供应多个前端（网站、移动应用、自助终端）。
  • 你想要结构化、经过校验的内容和带类型的 API，而不是文章加 meta 字段。

从 WordPress 迁移到 Tess

把你的文章类型和自定义字段建模为 Tess 内容类型（ACF 字段组很适合对应为组件），用 tess-transfer 导入，再用一个简短的脚本把文章从 WordPress REST API 迁移到 Tess GraphQL API。
