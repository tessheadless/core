Tess vs Directus

Plataforma de datos sobre bases SQL (Node.js)

Una plataforma Node.js que convierte una base de datos SQL existente en API REST y GraphQL, con una aplicación de administración.

Cara a cara

Tess comparado con Directus
CriterioTessDirectus
EnfoqueTess gestiona su propio almacenamiento y esquemaRefleja las tablas de una base de datos SQL existente
Bases de datosPostgreSQL, MySQL, SQLite, MongoDB, DynamoDB, RocksDBBases de datos SQL: PostgreSQL, MySQL, MariaDB, SQLite, MS SQL, Oracle, CockroachDB
APIGraphQL generado a partir de los modelosREST y GraphQL
Flujo de revisiónIntegrado, por tipo de contenidoSe construye con permisos y Flows
AutomatizaciónPlugins en cada escrituraFlows (automatización basada en eventos) integrados
LicenciaCommunity (uso personal) / Enterprise (uso comercial)Business Source License: gratuita por debajo de un umbral de ingresos, licencia comercial por encima

Elige Directus si…

  • Debes exponer una base de datos SQL existente tal cual.
  • Quieres flujos de automatización integrados.

Elige Tess si…

  • Partes de modelos de contenido, no de tablas existentes.
  • Necesitas NoSQL (MongoDB, DynamoDB), una base de datos integrada o AWS Lambda.

Pasar de Directus a Tess

Cada colección de Directus pasa a ser un tipo de contenido de Tess, y sus campos relacionales, campos RELATION. Escríbelos en el formato YAML de tess-transfer, impórtalos y copia los elementos mediante ambas API GraphQL.
