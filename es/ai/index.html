Servidor MCP integrado

Tu sitio web, gestionado hablando con tu IA.

Tess habla el Model Context Protocol, el estándar abierto que usan los asistentes de IA para trabajar con herramientas. Conecta Claude, Codex, OpenCode, Pi o cualquier cliente MCP en dos minutos y pide en lenguaje natural: «redacta una entrada sobre nuestra nueva versión», «corrige las erratas de la página de precios», «¿qué productos no tienen imagen?». Sin plugins que instalar ni código que escribir.

Lo que puedes pedir

Tu asistente lee primero tus modelos de contenido, así que conoce tus campos, relaciones y componentes sin ninguna configuración. Después trabaja como un editor que nunca se cansa:

  • Escribir: «Redacta tres entradas de blog a partir de estas notas de versión, con un resumen y etiquetas.»
  • Editar a gran escala: «Todas las descripciones de producto de más de 300 palabras: acórtalas y mantén el tono.»
  • Revisar: «¿Qué páginas publicadas no tienen meta description ni imagen de portada?»
  • Modelar: «Añade un tipo de contenido FAQ con una pregunta, una respuesta y una categoría.» (con un token Admin)
  • Publicar: «Publica los borradores que aprobé esta mañana.»
  • Responder preguntas: «¿Cuántos artículos publicamos cada mes este año?»

Funciona con cada modelo de contenido que creas, en cuanto lo creas: el servidor MCP expone toda tu API GraphQL mediante dos herramientas genéricas, get_schema y graphql_query.

Listo en dos minutos

  1. Actívalo en la configuración del servidor: TESS_MCP=true.
  2. Crea un token de API para tu asistente en el panel de administración (API tokens), con el rol que necesita: Contributor para escribir borradores, Member para solo lectura.
  3. Añade Tess a tu cliente de IA: la URL de tu servidor y el token en una cabecera Authorization: Bearer, como en el ejemplo. Claude Code, OpenCode, Codex y Pi lo aceptan en una sola línea de configuración.

Eso es todo: tu asistente ya ve tu contenido, con exactamente los permisos de su token. Para los clientes que solo ejecutan programas locales, como Claude Desktop, el comando tess mcp hace lo mismo a través de un pequeño proxy local.

Una IA que trabaja para ti, no a tus espaldas

Dar a una IA acceso a tu sitio web no debería significar perder el control. Con Tess no es así:

  • Las mismas reglas para todos. El asistente usa un token de API, y Tess aplica el rol y el alcance de ese token a cada llamada. Un token Member lee; un token Contributor escribe borradores, solo en los tipos de contenido que permites.
  • La última palabra es humana. Con los flujos de revisión, los cambios de la IA son borradores enviados a revisión: tu equipo los aprueba antes de que nada se publique.
  • Todo queda registrado. Cada cambio guarda quién lo hizo, así que siempre sabes qué ha hecho el asistente y puedes revocar su token con un clic.
  • Tus datos siguen siendo tuyos. Tess funciona en tus servidores y solo habla con el cliente de IA que conectas, y únicamente con el contenido al que llega su token.

Preguntas sobre IA y MCP

¿Qué herramientas de IA funcionan con Tess?

Cualquier cliente compatible con el Model Context Protocol: Claude Code, Claude Desktop, OpenCode, Codex, Pi, Cursor y más. Los clientes que admiten servidores remotos se conectan directamente a https://tu-servidor/mcp, con tu token de API en una cabecera Authorization: Bearer; otros, como Claude Desktop, ejecutan el proxy local tess mcp. La guía de MCP (en inglés) incluye la configuración de cada uno.

¿Cómo inicia sesión mi asistente de IA en Tess?

Con un token de API que creas en el panel de administración. El cliente lo envía en la cabecera Authorization: Bearer de cada petición, así Tess sabe qué token, y qué rol, está llamando. Guárdalo en una variable de entorno en lugar de en un archivo de configuración y revócalo con un clic si hace falta. Sin token, un asistente solo puede leer el contenido publicado.

¿El servidor MCP forma parte de la edición Community?

Sí. Está integrado en Tess, en todas las ediciones: sin complementos ni servicios adicionales. Permanece desactivado hasta que defines TESS_MCP=true.

¿Puede la IA borrar o estropear mi contenido?

Solo si le das un token que lo permita. Usa un token Contributor limitado a unos pocos tipos de contenido y activa los flujos de revisión: así la IA escribe borradores que tu equipo revisa y publica.

¿Funciona con mis propios modelos de contenido?

Sí, con todos, en cuanto los creas. El asistente lee primero tu esquema, así que no hay nada que configurar por modelo.
