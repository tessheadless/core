Funciones

Un binario, toda la plataforma de contenido

Tess reúne la API, el panel de administración y las reglas de negocio. Elige tu base de datos, tu almacenamiento multimedia y tu alojamiento.

Todas las funciones

  • Gestionado con IA

    Un servidor MCP integrado permite a Claude, Cursor y cualquier cliente MCP leer tus modelos y crear, editar y publicar contenido en lenguaje natural, con los mismos permisos que la API.

  • Modelos en tiempo de ejecución

    Crea tipos de contenido en el panel de administración o mediante la API, en producción. El esquema GraphQL se regenera al momento: sin recompilar ni volver a desplegar.

  • GraphQL primero

    Consultas tipadas, filtros, ordenación, paginación, relaciones y mutaciones generadas para cada modelo, con el IDE GraphiQL integrado.

  • Tu base de datos

    PostgreSQL, MySQL, SQLite, MongoDB, DynamoDB o RocksDB integrado. Todos los backends pasan la misma batería de pruebas de conformidad.

  • Flujos de revisión

    Borrador y publicación para cada entrada, más un flujo opcional enviar → aprobar por tipo de contenido, en todas las ediciones.

  • Roles y tokens con alcance

    Roles Owner, Admin, Contributor, Reviewer y Member, limitados a ciertos tipos de contenido si hace falta, y tokens de API con alcance limitado para las máquinas.

  • Plugins aislados

    Plugins WebAssembly que los administradores instalan en tiempo de ejecución, escritos en Rust, Go, JavaScript y más, con límites de tiempo y de memoria.

  • Serverless o contenedor

    Un solo binario funciona como servidor HTTP (Docker, VM, Kubernetes) o como función de AWS Lambda.

  • Biblioteca multimedia

    Subidas a almacenamientos compatibles con S3 (Garage, MinIO, AWS S3, Cloudflare R2) o al sistema de archivos local, con subidas directas prefirmadas.

  • Búsqueda de texto completo

    Indexación con Typesense sincronizada con tu contenido, detrás de una interfaz de motor de búsqueda intercambiable.

  • Privado por diseño

    Identificadores opacos, cifrados y con caducidad en la API: los identificadores de la base de datos nunca salen del servidor.

  • Modelos portables

    tess-transfer exporta los modelos de contenido y los usuarios a YAML o JSON, para versionarlos o copiarlos entre instancias.

Tipos de campo

TEXT (límites de longitud, formato por regex), MARKDOWN (HTML sin procesar rechazado), INT, FLOAT, BOOLEAN, DATETIME, DATE, UUID, PASSWORD (con hash, solo escritura), JSON, ENUM, RELATION (simple o múltiple), COMPONENT (grupos de campos reutilizables, simples o repetibles) y DYNAMIC_ZONE (una lista que mezcla componentes). Las páginas de este sitio están hechas con zonas dinámicas.
