Tess ou Directus

Plateforme de données sur bases SQL (Node.js)

Une plateforme Node.js qui transforme une base SQL existante en API REST et GraphQL, avec une application d'admin.

Côte à côte

Tess comparé à Directus
CritèreTessDirectus
ApprocheTess gère son propre stockage et son schémaReflète les tables d'une base SQL existante
Bases de donnéesPostgreSQL, MySQL, SQLite, MongoDB, DynamoDB, RocksDBBases SQL : PostgreSQL, MySQL, MariaDB, SQLite, MS SQL, Oracle, CockroachDB

LicenceCommunity (usage personnel) / Enterprise (usage commercial)Business Source License : gratuite sous un seuil de chiffre d'affaires, licence commerciale au-delà

Choisissez Directus si…

  • Vous devez exposer une base SQL existante telle quelle.
  • Vous voulez des flux d'automatisation intégrés.

Choisissez Tess si…

  • Vous partez de modèles de contenu, pas de tables existantes.
  • Vous avez besoin de NoSQL (MongoDB, DynamoDB), d'une base embarquée ou d'AWS Lambda.

Passer de Directus à Tess

Chaque collection Directus devient un type de contenu Tess, et ses champs relationnels deviennent des champs RELATION. Écrivez-les au format YAML de tess-transfer, importez-les, puis copiez les éléments via les deux API GraphQL.
