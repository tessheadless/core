Tess ou Sanity

Plateforme de contenu hébergée avec un studio open source

Un Content Lake hébergé, avec un studio d'édition React open source et personnalisable, et son propre langage de requête, GROQ.

Côte à côte

Tess comparé à Sanity
CritèreTessSanity
Mode de distributionUn logiciel que vous exploitez vous-mêmeContent Lake hébergé ; le studio est open source et déployable soi-même
Modèles de contenuInterface d'admin ou API, appliqués immédiatementSchémas en code JavaScript/TypeScript
APIGraphQL généré à partir des modèlesGROQ, plus une API GraphQL déployable
ÉditionInterface d'admin avec brouillons et relecturesÉdition collaborative en temps réel dans un studio très personnalisable
Emplacement des donnéesVos serveurs et votre base de donnéesLe cloud de Sanity
TarifsCommunity gratuite pour un usage personnel ; licence Enterprise pour un usage commercialOffre gratuite, puis offres payantes selon l'usage et le nombre de sièges

Choisissez Sanity si…

  • Vous avez besoin de collaboration en temps réel et d'un studio d'édition très personnalisé.

Choisissez Tess si…

  • Vous voulez votre contenu dans votre propre base de données, avec une API GraphQL standard et aucun langage de requête à apprendre.

Passer de Sanity à Tess

Les types de documents et les objets de Sanity se traduisent en types de contenu et composants Tess ; les tableaux de types mixtes deviennent des champs DYNAMIC_ZONE. Importez les modèles avec tess-transfer, puis copiez les documents d'un export Sanity via l'API GraphQL de Tess.

Lire le guide d'import et d'export

Informations vérifiées le 20 octobre 2026 dans la documentation publique de Sanity (www.sanity.io). Les produits évoluent vite : consultez le site de l'éditeur pour les dernières fonctionnalités et les tarifs.
