Tess vs Sanity

Hosted content platform with an open-source studio

A hosted Content Lake with a customizable, open-source React editing studio and its own query language, GROQ.

Side by side

Tess compared with Sanity
CriterionTessSanity
DeliverySoftware you run yourselfHosted Content Lake; the studio is open source and self-deployable
Content modelsAdmin UI or API, applied immediatelySchemas in JavaScript/TypeScript code
APIGraphQL generated from the modelsGROQ, plus a deployable GraphQL API
EditingAdmin UI with drafts and reviewsReal-time collaborative editing in a highly customizable studio
Data locationYour servers and your databaseSanity's cloud
PricingCommunity free for personal use; Enterprise license for commercial useFree tier, then paid plans by usage and seats

Choose Sanity if…

  • You need real-time collaboration and a deeply customized editing studio.

Choose Tess if…

  • You want your content in your own database, with a standard GraphQL API and no query language to learn.

Moving from Sanity to Tess

Sanity document types and objects map to Tess content types and components; arrays of mixed types become DYNAMIC_ZONE fields. Import the models with tess-transfer, then copy documents from a Sanity export through the Tess GraphQL API.
